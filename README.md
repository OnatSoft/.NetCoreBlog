# .NetCoreBlog
Asp.Net Core 5.0 Blog Demo Project Camp (Certificied)

Bu proje kampında ASP.Net Core 5.0 ile Entity Framework Core, N-Tier Architecture, Fluent Validation, Identity, JWT(Json Web Token), AJAX işlemleri, Sayfalama Yapısı, Yazarlar Arası Mesajlaşma, API ile Hava Durumu Bilgisi Çekme, Swagger ve Postman ile CRUD işlemleri, Codefirst, MSSQL Server, Backend olarak C#, Frontend olarak Html-Css-Bootstrap kullanılarak Kullanıcı, Yazar ve Admin panelli gelişmiş bir blog sitesi geliştirilmiştir.

Proje kampı YouTube'da 150 dersten oluşmakta ve eğitmen Murat Yücedağ olmaktadır, oynatma listesine <a href="https://www.youtube.com/playlist?list=PLKnjBHu2xXNNkinaVhPqPZG0ubaLN63ci" target="_blank">buradan</a> ulaşabilirsiniz.
